## 功能调整

### 单机客户绑定

- 新增稳定 `sys_user.user_id`、`robot.robot_id` UUID，保留现有 username / SN 主键和历史外键兼容。
- `user_robot_binding` 为普通账号保存一个机器人 UUID；本版同时限制一台机器人只被一个普通账号绑定，避免无意共享客户设备。占用冲突返回 409，须先明确解绑。
- 客户名称存于机器人主台账 `fields.customer`，用于展示，不作为权限条件。用户同名、改名、SN 迁移均不改变归属。
- 建立、调整、解除绑定均在事务中保存；`binding_history` 记录人员 UUID/账号、时间、原/新机器人、原/新客户名称与原因，另追加业务审计。
- 未绑定时列表为空，显示“尚未绑定机器人，请联系管理员”。列表、搜索、详情、标签、二维码、导出及接口统一执行 UUID 范围与字段过滤。
- 普通用户仅能修改昵称。客户名称、版本、自定义字段和绑定关系均不能由普通用户修改。解绑/重新绑定后的下一次请求立即使用新范围；已下载文件或人已看到的信息无法远程撤回。

### 主台账列管理

- 新增管理员入口，直接配置机器人主台账，不借用补充业务表。
- 支持名称、分组、显示顺序、必填、客户可见；新建类型可选文本、日期、MAC、数字、是/否。新增默认内部可见。
- 字段创建后的类型保持固定，避免历史值被重新解释；需要其他类型时新建字段。支持归档、恢复及配置修改的审计。
- 列配置同步影响列表、详情、编辑/新建表单、常规 CSV 导出。数字 0、false、小数与历史空值正确区分。
- 历史缺失值不自动补造；新记录遵循必填配置，编辑历史记录时未触及的空值不强制补填。
- 归档保留字段定义、原值和历史。SN、模块关联是投影列，底层身份/装拆继续存在；客户绑定、昵称编辑白名单、流程及审计也不因展示列归档失效。界面说明这些边界。
- 新增 SN 和 13 个模组 SN 投影定义，兼容原表 46 列及已有扩展字段，没有重复导入原表。

### 用户管理与会话

- 管理员可查看、新增用户，保存角色、启停、重置密码和绑定；返回内容不含密码或密码散列。
- BCrypt 保存密码。密码重置仅记录“已重置”的审计，不记录明文。权限变更使用 `auth_version`，停用、角色变化、密码重置后旧会话被拒绝，重新登录读取最新配置。
- 技术人员与普通用户直接请求用户管理、字段定义接口返回 403，不能提升自身权限。
- 当前管理员不能停用或降级自己；账户变更使用事务和公共锁，保留至少一个有效管理员。
- 技术人员可以新增/修改机器人及补充业务记录，禁止删除业务记录和修改表结构；自动生成 SN 仍需专项授权。

## 已知边界和剩余问题

- 用户原始管理员全面失败的现场触发条件尚未确认；若仍出现，需对应操作、错误提示与发生时间定位。当前规定的管理员功能均已通过保存和权限验收。
- 导入来源是已有来源文件、工作表/单元格、映射、导入决策及快照追溯，**没有任意 Excel 网页上传、预览或覆盖导入**。
- Flash 仍为写入任务和人工回读比对，没有设备协议联动；不声称执行真实硬件写入。
- 本版用户绑定为双向一对一；多个家庭成员共享同一机器人尚不支持。补充业务表面向内部角色，不参与普通用户设备页面。
- 已归档主台账列可恢复；补充表/记录删除保留底层值和审计，但没有完整回收站恢复 UI。审计普通页面/导出最多 2000 条，数据库历史继续保存。
- 本次未新建开机自启服务、防火墙规则或 HTTPS。长期开机部署按 README 配置；局域网其他设备连通仍取决于实际网络与防火墙。
- 回退需用升级前备份恢复至独立库并配套旧 JAR，不能仅用旧 JAR 连接已升级 schema，也不能覆盖 v1 数据库。

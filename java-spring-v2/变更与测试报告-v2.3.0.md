# Valenbot v2.3.0 变更与测试报告

日期：2026-09-16。工程：java-spring-v2。基线：已发布的 v2.2.0。

## 已实现

1. 原 46 列生命周期信息表的空白 XLSX 模板及下载接口；管理员、技术人员可用。
2. 文件格式、表头、数据类型、范围、SN、模组等校验，行级预览、账号绑定的一次性确认令牌、整批事务新建。支持空 SN 分配、未用新 SN 登记与预留编号占用；不覆盖原设备。
3. 保存原始单元格、映射、源文件摘要、原行号、最终 SN、操作者及原因。版本空白不补造，客户名称不隐式绑定用户。

5. HTTPS 配置、TLS 1.2/1.3、Secure Cookie、基于可信配置的 HTTP 跳转，以及 HTTPS 二维码地址。HTTP POST 不处理登录或业务提交。

使用方式、权限矩阵及事务时序见 [v2.3 说明](v2.3-Excel导入与HTTPS说明.md)。

## 部署与验证边界

- 本机 HTTPS 服务为 8443，HTTP 8082 只作跳转；无开机服务或证书自动续签。
- Windows 根证书导入请求尚需系统确认。实际浏览器尝试访问时返回 `ERR_CERT_AUTHORITY_INVALID`，因此不能宣称本机或其他设备均已完成无警告浏览器验收。使用指定 CA 且验证主机名的真实 TLS 请求已通过。
- 自动审批拒绝额外启动后台 UI 测试实例，原因只返回 `blocked by policy`。本次没有完成导入表单的真实浏览器交互及全屏宽检查；不能用接口通过代替这部分验收。
- 原 v1 仍在同一主机使用 HTTP，本版暂不启用跨端口生效的 HSTS，避免影响保留的旧入口；新 v2 的 HTTP 请求仍被前置过滤器跳转或拒绝。
- 仅固定模板的追加新建；不支持任意 Excel 列映射、覆盖更新、历史质检/交付迁移或自动硬件 Flash。预览只存当前进程内，适用于当前单实例局域网部署。

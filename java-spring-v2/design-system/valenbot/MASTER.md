# Valenbot 工业工作台

用户于 2026-09-15 选择方案 A。基于 v1.0.0 功能基线，使用原生 HTML/CSS/JavaScript 与 Thymeleaf，不更换框架。

## 产品与视觉

- 服务对象：日常登记机器人、装拆部件和处理维修的管理员、维护人员与查询人员。
- 深蓝固定导航、浅灰工作区、白色数据面板、蓝色主要操作。表格与表单优先，品牌位使用 Valenbot 文字标识。
- 字体：Windows Bahnschrift 用于拉丁品牌和数字；正文 Segoe UI / Microsoft YaHei / PingFang SC / sans-serif。局域网离线可读，不加载远程字体。
- 字级：正文 16px，表格与标签 14px，辅助说明 12–13px，页面标题 28px，主指标 32px。数字使用等宽数字特性，长编号允许换行。
- 颜色：导航 #142B49；主操作 #285DD4；深色文字 #203047；辅助文字 #596B82；背景 #F3F6FA；面板 #FFFFFF；边线 #DCE4ED。
- 状态：可用/完成为绿色文字和标签，待检/处理中为琥珀色，故障/报废为红色。状态始终包含中文，不单凭颜色表达。
- 间距 4/8/12/16/24/32px；普通按钮与表单控件至少 44px 高；表格操作在桌面保持紧凑，手机使用 44px 点击区。
- 面板 10px 圆角；按钮 6px；弹窗 14px。柔和阴影仅用于弹窗，普通表格以边线区分。

## 各页面

登录页采用品牌说明与登录表单并排，移动端表单优先；不引入远程图片。
机器人和部件列表保留搜索，统计明确标为当前查询或当前列表；不展示虚构设备或服务状态。
档案将整机版本、Orin 版本与二维码分区；装配与维修具有明确的新增操作。
维修处理显示进度阶段、版本快照和处理表单；用户管理突出三种角色的能力区别。
所有新增、编辑、装拆表单统一标题、字段间距、取消与确认位置，错误保留在表单内，提交期间防重复。
表格可在容器内横向滚动，页面本身不应横向溢出；对话框在小屏单列布局。

## 交互与验收

原生 dialog 保留焦点约束与 Esc；关闭后恢复焦点，刷新列表时提供稳定焦点落点。显式 label、可见焦点环、文字错误、跳转正文链接与减少动态效果支持。
验证 375、768、1024、1440 宽度；检查真实数据的长编号、空列表、表单错误与权限展示。
